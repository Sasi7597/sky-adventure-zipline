# Sky Adventure's Zip Line

Responsive single-page website for Sky Adventure's 1 KM zipline experience.

## Current build
- Premium 5-slide auto-playing hero carousel
- Desktop, tablet and mobile navigation
- About, experience journey, gallery, location, FAQ and booking/contact sections
- Frontend-only booking enquiry form (no backend/API connected yet)
- Packages section removed
